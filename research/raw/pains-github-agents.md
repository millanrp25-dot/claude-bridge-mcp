# Pain mining — GitHub issues & discussions, AI agent / developer tooling (B2B)

- Window: 2026-10-16 → 2026-11-15. Collected 2026-11-15. Evidence only, no ideas.
- Method: GitHub REST search API (`search/issues`, per repo, sorted by 👍 and by comments, plus 30 keyword queries across repo groups — ~1,900 unique issues scanned), then GitHub web pages for comments and Discussions.
- Quote provenance (column "Src"):
  - **API** = copied from the issue body returned by the GitHub API. Verbatim. Markdown bold/italics kept; where the source wrapped a sentence across lines the line breaks were removed; "…" marks a cut inside a sentence.
  - **WEB** = copied from the rendered page through a fetch tool that caps quotes at ~125 characters. The text is the verbatim *opening* of the comment; "[cut]" marks where the tool truncated it. Reaction counts are as displayed on the page.
  - **TITLE** = only the title is quoted (verbatim); body not captured.
- Engagement = 👍 on the issue/comment, total comment count on the issue (API figures at collection time).
- Caveats: many issue bodies in this window are visibly AI-drafted (the complaint is still the author's). Records flagged *vendor* come from someone who discloses or appears to be building a product in the area. One comment in openai/codex#59060 contained text addressed to AI agents; it was ignored and is not recorded.
